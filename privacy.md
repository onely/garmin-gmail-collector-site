# Privacy Policy

Garmin Gmail Collector is a personal-use application.

## Data collected
The application collects Garmin fitness and wellness information to prepare personal summaries.

## Google data
The application uses Google OAuth and the Gmail API to send emails from the authorized account.

## Storage
OAuth credentials are stored privately on the application owner's server and are not published.

## Data sharing
The application does not sell or share user information with advertisers or unrelated third parties. Data is transmitted through Gmail to the recipient configured by the owner.

## Revoking access
The owner can revoke Google access at https://myaccount.google.com/connections.
